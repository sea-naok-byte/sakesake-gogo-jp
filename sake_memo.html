クラウド同期の設定
Firebase（永久無料）でデータをクラウドに保存します。
設定すると複数のデバイスで同じデータが使えます。
設定手順
1
console.firebase.google.com を開き、Googleアカウントでログイン
2
「プロジェクトを追加」→ 任意の名前（例：sake-memo）を入力 → 「続行」を2回押して「プロジェクトを作成」
3
左メニュー「構築」→「Firestore Database」→「データベースの作成」→「次へ」→「作成」
4
「ルール」タブをクリック → 表示されているルールを全部消して以下を貼り付け → 「公開」
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
5
左上の「プロジェクトの概要」横の⚙️→「プロジェクトの設定」→ 下にスクロールして「アプリを追加」→ ウェブ（</>）をクリック → ニックネームを入力して「アプリを登録」
6
画面に表示されるfirebaseConfigの中の値を下に入力してください
Firestore（テキストデータ）
Realtime Database（写真データ）
Firebase ConsoleのRealtime Databaseに表示されているURLを入力してください。
例：https://プロジェクト名-default-rtdb.firebaseio.com
